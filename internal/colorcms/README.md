# Embedded ICC conversion

LittleCMS 2.19.1 is compiled to WASI WebAssembly and embedded in the Go binary.
The runtime is wazero; no native CMS library is loaded at runtime. Each transform
uses an isolated module with a 512 MiB linear-memory limit and context cancellation.
RGB, grayscale and CMYK matrix/TRC and LUT ICC profiles use relative colorimetric
rendering into sRGB, without black-point compensation. Out-of-gamut values are
clipped; this is a specified color conversion, not a promise of identical colors
on arbitrary displays. Alpha is preserved independently at 16-bit precision.

PNG cHRM/gAMA and SDR CICP metadata use virtual ICC profiles through this same
engine: sRGB, BT.709/601 and linear transfer curves; BT.709, Display P3 D65 and
BT.2020 primaries. PQ and HLG preserve original resources until an explicit HDR
tone-mapping policy exists. Invalid or ambiguous color metadata also preserves
the original resource. AVIF primary-item presentation properties apply integer
clean-aperture crops, rotations and mirrors before comparison; fractional or
out-of-bounds crops preserve the original resource.

The image engine defaults to `color_policy: preserve`, which keeps resources
whose color would need normalization. `color_policy: srgb` explicitly opts into
the conversion above and identifies the result as an appearance change. A metric
against the clipped reference is never exposed as fidelity to the wide-gamut
original. Pixel-strict profiles retain the original color resource.

Upstream: https://github.com/mm2/Little-CMS/tree/lcms2.19.1
Source archive SHA256: `267705e278e2f7c2fb886c259dadcbaeb2be52748bcbc71c79f08aacacb7a709`.
The upstream MIT license is in LICENSE.lcms2. Rebuild with `sh build.sh` and a WASI
SDK (`WASI_SDK_PATH`, default `/opt/wasi-sdk`).

The six small profiles in testdata and their 16-bit input/output vectors are
generated by `wasm/generate_corpus.c`. It uses native LittleCMS only to generate
the checked-in oracle; normal Go tests and deployed conversion need no shared
library. The LUT profiles are generated fixtures, not redistributed proprietary
printer profiles. Regenerate with a native C compiler and `-llcms2 -lm`.
